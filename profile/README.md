# WorkFlow FATEC

Sistema de secretaria acadêmica desenvolvido pela turma **4º DSM 2026**: abertura e acompanhamento de chamados, catálogo de serviços, caixa de sugestões e notificações para alunos e funcionários.

## Repositórios

| Repositório | Conteúdo |
|---|---|
| [backend_fatecProjeto](https://github.com/4dsm2026/backend_fatecProjeto) | API — Fastify, Prisma, MySQL |
| [frontend_fatecProjeto](https://github.com/4dsm2026/frontend_fatecProjeto) | Interface web — Next.js |
| [docs_fatecProjeto](https://github.com/4dsm2026/docs_fatecProjeto) | Documentação — [abrir o site](https://4dsm2026.github.io/docs_fatecProjeto/) |
| [test_fatecProjeto](https://github.com/4dsm2026/test_fatecProjeto) | Testes de ponta a ponta (Selenium) |

📋 **Quadro do projeto:** [WorkFlow 2026](https://github.com/orgs/4dsm2026/projects/3) — issues e PRs de todos os repositórios, por sprint, equipe e prioridade.

## Como participar

1. Leia o [guia de contribuição](https://github.com/4dsm2026/.github/blob/main/CONTRIBUTING.md).
2. Para rodar o projeto localmente, siga o README do [backend](https://github.com/4dsm2026/backend_fatecProjeto#readme) e depois o do [frontend](https://github.com/4dsm2026/frontend_fatecProjeto#readme).
3. Escolha uma issue da sprint, atribua-se e abra o Pull Request para `develop`.
